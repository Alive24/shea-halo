## OpenWiki

This repository uses OpenWiki for reviewed code documentation. Start with `openwiki/quickstart.md`, then follow its links to architecture, workflows, domain concepts, operations, integrations, testing guidance, and source maps.

OpenWiki updates are currently run manually and committed only after review. Treat `openwiki/INSTRUCTIONS.md` as the human-owned scope brief. Do not hand-edit generated OpenWiki pages unless explicitly asked; prefer updating source code or canonical docs and then regenerating the wiki.
